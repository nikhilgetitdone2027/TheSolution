# Model card

## Model purpose

Estimate the product mass distribution of mixed-plastic pyrolysis from material fractions and process inputs, so an operator can compare configurations inside the range of the training data.

The model is a decision-support component. It is not a laboratory instrument.

## Training data

- Identifier: `hackathon-demo-illustrative-v1`
- Label: Hackathon Demo Dataset — Illustrative
- Nature: synthetic response surface with Gaussian noise, generated by `ml/app/simulator.py`
- No experimental dataset was supplied with the project
- Targets: `oil_pct`, `gas_pct`, `char_pct`, `other_product_pct`
- Features actually used are listed in `ml/artifacts/model_meta.json` after training. `other_pct` is omitted when the material fractions sum to 100%, because it is the closure of that balance. Elemental columns are omitted when the file does not contain them.

## Evaluation method

1. Hold out 20% of the rows (`random_state` 20260330).
2. Compare linear regression, random forest, and gradient boosting with k-fold cross-validation on the training split only.
3. Select the candidate with the lowest cross-validated mean absolute error.
4. Refit that candidate on the training split.
5. Report MAE, RMSE, and R² once on the holdout split.
6. Compute permutation importance on the holdout split.

Scaling for the linear model sits inside a scikit-learn pipeline, so it is fit on training folds only.

The training run that produced `ml/artifacts/model_meta.json` selected **Linear Regression** because it had the lowest cross-validated MAE. On that run the training-split cross-validation scores were:

| Model | MAE | RMSE | R² |
| --- | --- | --- | --- |
| Linear Regression (selected) | 2.357 | 2.994 | 0.746 |
| Gradient Boosting | 3.197 | 4.017 | 0.594 |
| Random Forest | 3.532 | 4.531 | 0.522 |

Holdout, after refitting the selected model on the training split: MAE 2.184, RMSE 2.776, average R² 0.762. Per-target holdout R² was 0.918 for oil, 0.893 for gas, 0.437 for char, and 0.801 for other products. Char is the weakest target under this noise level. These figures describe the illustrative simulator only.

Retraining with the same seed reproduces this selection. If the dataset file changes, trust the metrics in Model Trust rather than this table.

## Inference post-process

Negative raw outputs are clipped at zero and the four products are renormalized to 100%. The interface labels the result as a model estimate.

If the selected model is a random forest, the interface also shows the standard deviation across trees. That is ensemble spread, not a calibrated prediction interval. Other selected models do not show a spread.

## Out-of-distribution behavior

Inputs outside the training-split minimum and maximum are flagged as extrapolation. The optimizer does not search outside that range and does not present an extrapolated point as a recommendation.

## Intended use

Hackathon demonstration and later evaluation against a real pyrolysis dataset with the same adapter: inspect composition, predict product fractions, compare pathways, and test process changes inside the supported range.

## Non-intended use

Plant design, permitting, regulatory reporting, emission inventories, price forecasts, or a substitute for laboratory yields.

## Explainability

Global explanation uses permutation importance and is labeled as such. SHAP is not a dependency. Local explanation changes one input by 10% of its training range, stays inside that range, and reports the change in the model output.
