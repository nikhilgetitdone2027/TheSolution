# Dataset schema

No experimental dataset was supplied with this repository. The file `ml/data/demo_dataset.csv` is generated by `ml/app/simulator.py` and is labeled **Hackathon Demo Dataset — Illustrative**.

Elemental columns are not stored in that file. They are calculated at request time from polymer repeat units when the request asks for a chemical profile. Optional elemental columns below are accepted if a later dataset contains independent measurements.

| Column | Type | Unit | Description | Required | Source | Valid range in the demo generator |
| --- | --- | --- | --- | --- | --- | --- |
| sample_id | string | — | Row identifier | optional | generator | — |
| waste_category | string | — | `mixed_plastic` for the implemented pathway | optional | generator | mixed_plastic |
| pe_pct | number | wt% dry blend | Polyethylene fraction | required for the current model | input | composition sums to 100 |
| pp_pct | number | wt% dry blend | Polypropylene fraction | required for the current model | input | composition sums to 100 |
| pet_pct | number | wt% dry blend | Polyethylene terephthalate fraction | required for the current model | input | composition sums to 100 |
| ps_pct | number | wt% dry blend | Polystyrene fraction | required for the current model | input | composition sums to 100 |
| pvc_pct | number | wt% dry blend | Polyvinyl chloride fraction | required for the current model | input | composition sums to 100 |
| other_pct | number | wt% dry blend | Uncharacterized remainder | required for the mass balance | input | omitted from the model when the six fractions sum to 100 |
| moisture_pct | number | wt% as received | Moisture | required for the current model | input | 0.2–5 in the generator |
| particle_size_mm | number | mm | Nominal particle size | required for the current model | input | 1–8 in the generator |
| feed_rate_kg_h | number | kg/h | Feed rate | required for the current model | input | 6–28 in the generator |
| temperature_c | number | °C | Pyrolysis temperature used as a model input | required for the current model | input | 430–530 in the generator |
| residence_time_min | number | min | Residence time | required for the current model | input | 20–80 in the generator |
| oil_pct | number | wt% of products | Illustrative oil target | required to train | simulator | sums to 100 with the other products |
| gas_pct | number | wt% of products | Illustrative gas target | required to train | simulator | sums to 100 with the other products |
| char_pct | number | wt% of products | Illustrative char target | required to train | simulator | sums to 100 with the other products |
| other_product_pct | number | wt% of products | Illustrative residual product target | required to train | simulator | sums to 100 with the other products |
| source | string | — | Dataset label | optional | generator | Hackathon Demo Dataset — Illustrative |
| carbon_pct | number | wt% | Uploaded elemental carbon | optional | uploaded measurement only | 0–100 if present |
| hydrogen_pct | number | wt% | Uploaded elemental hydrogen | optional | uploaded measurement only | 0–100 if present |
| oxygen_pct | number | wt% | Uploaded elemental oxygen | optional | uploaded measurement only | 0–100 if present |
| nitrogen_pct | number | wt% | Uploaded elemental nitrogen | optional | uploaded measurement only | 0–100 if present |
| chlorine_pct | number | wt% | Uploaded elemental chlorine | optional | uploaded measurement only | 0–100 if present |
| biogenic_carbon_pct | number | wt% | Biogenic carbon fraction | optional | uploaded only | not in the demo file |
| fossil_carbon_pct | number | wt% | Fossil carbon fraction | optional | uploaded only | not in the demo file |
| inert_carbon_pct | number | wt% | Inert carbon fraction | optional | uploaded only | not in the demo file |

Generator bounds are the bounds of the illustrative simulator. They are not industrial safety limits.

Header aliases such as `PE`, `temperature`, and `residence_time` are accepted by the parser. Unknown columns are kept on the sample and are not invented into model features.
